Honest scoring. Every time.

Many "trust checkers" return a green score for everything. {{ site_name }} deducts points only from evidence it actually detects, and returns Insufficient Evidence when there is not enough to judge - short inputs, failed OCR, offline sites, unmatched claims.

  • OCR with confidence scoring
  • Tampering detection via error-level analysis
  • Domain age & redirect chain inspection
  • Cross-check against trusted news feeds
  • Claim verification against a seeded evidence base
